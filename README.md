## 📋 About

A fully responsive school website template designed to serve as a real-world client deliverable. Built with semantic HTML and Tailwind CSS, this project demonstrates the ability to structure, style, and ship a multi-page website without relying on JavaScript frameworks — just clean fundamentals.

---

## 📄 Pages

| Page | File | Description |
|---|---|---|
| Home | `index.html` | Landing page with hero section and school overview |
| About | `about.html` | School history, mission, and values |
| Programs | `programs.html` | Academic programmes and courses offered |
| Admissions | `admissions.html` | Admissions process and requirements |
| Contact | `contact.html` | Contact form and school location details |

---

## ✨ Features

- Fully responsive — works on mobile, tablet, and desktop
- Clean multi-page navigation with consistent header and footer
- Semantic HTML5 structure throughout
- Tailwind CSS utility-first styling
- Fast load times — no heavy frameworks or dependencies
- Deployed and live on Vercel

## 🚀 Getting Started

### View it live
👉 **[school-website-black-ten.vercel.app](https://school-website-black-ten.vercel.app)**

### Run it locally

```bash
# Clone the repo
git clone https://github.com/Eldren-cmd/school-website.git

# Open in your browser
cd school-website
open index.html
```

No build step required — just open `index.html` directly in your browser.
